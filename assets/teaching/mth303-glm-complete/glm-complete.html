    2 GLM 的统一框架

    一个 GLM 包含三个组成部分：

    • 随机部分： 给定协变量时的响应分布，例如 Bernoulli 或 Poisson。
    • 系统部分： 线性预测子 ηi=xiTβ\eta_i=x_i^T\beta。
    • 链接函数： g(μi)=ηig(\mu_i)=\eta_i，其中 μi=E(Yi∣xi)\mu_i=E(Y_i\mid x_i)。

    方差函数也是模型的一部分。在本文的标准例子中，Bernoulli 响应有 V(μ)=μ(1−μ)V(\mu)=\mu(1-\mu)，Poisson 响应有 V(μ)=μV(\mu)=\mu。因此，GLM 不只是“换了一个误差分布的线性模型”；均值、链接以及均值—方差关系都需要考虑。

    模型 响应变量 常用链接 glm() 中的族
    Logistic 二分类或分组二项 Logit binomial("logit")
    Probit 二分类或分组二项 Probit binomial("probit")
    Poisson 计数 Log poisson("log")
    Quasi-Poisson 过度离散计数 Log quasipoisson("log")

    2.1 板书建议

    写下 g{E(Y∣X)}=Xβg\{E(Y\mid X)\}=X\beta 并始终保留。之后每遇到一个模型，都让学生指出 YY、E(Y∣X)E(Y\mid X)、gg，以及系数在哪一个尺度上具有线性关系。

    3 Logistic 回归：基础与解释

    对于二分类响应 Yi∈{0,1}Y_i\in\{0,1\}，定义

    πi=P(Yi=1∣xi),log(πi1−πi)=xiTβ. \pi_i=P(Y_i=1\mid x_i),\qquad \log\left(\frac{\pi_i}{1-\pi_i}\right)=x_i^T\beta.

    等式左侧是对数优势。逆链接为

    πi=exp(xiTβ)1+exp(xiTβ)=plogis(xiTβ). \pi_i=\frac{\exp(x_i^T\beta)}{1+\exp(x_i^T\beta)} =\operatorname{plogis}(x_i^T\beta).

    曲线被限制在 0 与 1 之间，但“预测概率不越界”本身并不能证明模型拟合良好。

    3.1 必须区分的五个量

    当 xjx_j 增加一个单位、模型中的其他项保持不变时：

    1. 线性预测子改变 βj\beta_j。
    2. 对数优势改变 βj\beta_j。
    3. 优势乘以 exp(βj)\exp(\beta_j)。
    4. 概率通常不会改变一个固定数值。
    5. 概率也不会乘以 exp(βj)\exp(\beta_j)。

    若基线概率为 π0\pi_0，则基线优势为 π0/(1−π0)\pi_0/(1-\pi_0)。优势比为 2 表示优势翻倍，而不是概率翻倍。新概率为

    π1=2π0/(1−π0)1+2π0/(1−π0)=2π01+π0. \pi_1=\frac{2\pi_0/(1-\pi_0)}{1+2\pi_0/(1-\pi_0)} =\frac{2\pi_0}{1+\pi_0}.

    对于连续预测变量，βj\beta_j 表示每增加一个单位时，对数优势的改变量。它不是通常 log–log 模型意义下的弹性。概率对 xjx_j 的局部斜率为 βjπ(1−π)\beta_j\pi(1-\pi)，所以它依赖于当前概率。

    建议按以下顺序讲 summary() 输出：

    1. Estimate： 在模型其他项不变时，每增加一个单位，对数优势的改变量。
    2. Std. Error： 系数估计在 logit 尺度上的不确定性。
    3. z value 和 p 值： 单个系数的 Wald 推断，不是预测重要性的度量。
    4. Null deviance 和 residual deviance： 用于拟合模型比较，不能单独证明模型充分。
    5. AIC： 对相同响应和相同观测所拟合模型的拟合—复杂度准则，不是绝对的拟合优度分数。

    一个单位的优势比可能不便交流。应在取指数前重新缩放：例如，余额增加 100 个单位时，对数优势改变 100β̂balance100\hat\beta_{\text{balance}}，优势乘以 exp(100β̂balance)\exp(100\hat\beta_{\text{balance}})。不能把“一个单位的概率差”简单乘以或取幂来得到 100 个单位的概率变化。

    5 使用 ggplot2 做 Logistic 诊断

    诊断流程应分别回答不同问题：

    问题 有用工具 不应得出的结论
    函数形式是否合适？ 残差对预测变量或 η̂\hat\eta、平滑曲线、样条比较 η̂\hat\eta 对 xx 机械地呈直线，不能证明线性假设成立
    是否存在异常观测？ 标准化残差、杠杆值、Cook 距离 超过阈值不等于应该删除数据
    预测是否校准？ 校准图，最好使用验证数据 准确率高不必然表示校准好
    预测变量是否冗余？ VIF 或广义 VIF，并结合专业知识 VIF 小于 5 不是绝对保证
    观测是否独立？ 研究设计和残差结构 Q–Q 图不能证明独立性

    对于二分类数据，普通 deviance 和 Pearson 残差不需要呈正态。随机分位数残差通过随机化，使其在模型正确时更便于评估分布；其 Q–Q 图是诊断辅助工具，不是模型正确性的普遍证明。

    7 计数数据的 Poisson 回归

    对于计数响应，

    Yi∣xi∼Poisson(μi),log(μi)=xiTβ, Y_i\mid x_i\sim\operatorname{Poisson}(\mu_i),\qquad \log(\mu_i)=x_i^T\beta,

    8 过度离散与 quasi-Poisson

    10 Poisson 率模型与 offset

    当暴露量不同时，将期望计数写成

    μi=miλi, \mu_i=m_i\lambda_i,

    其中 mim_i 是暴露量，λi\lambda_i 是每单位暴露量的事件率。使用 log 链接时，

    log(μi)=log(mi)+xiTβ. \log(\mu_i)=\log(m_i)+x_i^T\beta.

    11 扩展模块 A：估计、不确定性与模型推断

    本模块不属于两小时核心路线的必讲内容，但完整的 GLM 课程应当覆盖这些理论。

    11.1 glm() 估计的是什么

    对于参数化 GLM，通常使用极大似然法估计系数。对数似然为 ℓ(β)=∑iℓi(β)\ell(\beta)=\sum_i\ell_i(\beta)，得分方程令其关于 β\beta 的导数为零。对于 logit 和 log 链接，这些方程是非线性的，通常没有闭式系数公式。

    R 使用迭代加权最小二乘法（IRLS），在这里也称 Fisher scoring。直观地说，每次迭代针对一个工作响应求解加权最小二乘问题，更新 β̂\hat\beta，然后重复直到估计稳定。因此，Fisher scoring iterations 是计算过程信息，不是模型质量指标。

    在标准参数化二项和 Poisson GLM 中，离散参数固定为 1。输出中的 z 统计量使用大样本正态近似。算法收敛并不表示模型设定正确。

    11.2 Deviance 与似然

    对于拟合模型 MM，deviance 将其对数似然与饱和参照模型比较。对固定数据集，较小的 residual deviance 表示样本内拟合更接近，但增加参数通常会降低 deviance。因此，residual deviance 不能单独作为选模规则。

    常用对象包括：

    • logLik(fit)：最大化后的对数似然。
    • deviance(fit)：残差 deviance。
    • df.residual(fit)：残差自由度。
    • AIC(fit)：对于估计 kk 个参数的参数模型，为 −2ℓ+2k-2\ell+2k。

    11.3 Wald、轮廓似然与似然比方法

    这些方法相关，但并不相同：

    • Wald 区间使用 β̂±z1−α/2SE(β̂)\hat\beta\pm z_{1-\alpha/2}\operatorname{SE}(\hat\beta)。计算快，在链接尺度上对称，但在稀有事件、分离或小样本下可能表现不佳。
    • 轮廓似然区间在一系列系数取值上重新优化其他参数。它可以不对称；当 Wald 近似可疑时通常更值得考虑。
    • 似然比检验比较嵌套模型的最大化似然。通常的卡方参照分布依赖正则条件和适当的参数模型。

    11.4 收敛、巨大系数与分离

    当预测变量能够几乎完全区分两个响应类别时，会出现完全分离或准完全分离。此时有限的极大似然估计可能不存在。警示信号包括：

    • 系数或标准误的绝对值异常大；
    • 拟合概率极其接近 0 或 1；
    • 不收敛或 IRLS 迭代次数很多；
    • 出现 fitted probabilities numerically 0 or 1 occurred 警告。

    13.1 先划分数据，再评估

    模型诊断关注假设和函数形式是否合理；预测评估关注模型在未参与拟合的观测上表现如何。预测项目需要二者，任何一方都不能替代另一方。

    stratified_training_rows <- function(y, proportion = 0.7) {
  rows_by_class <- split(seq_along(y), y)
  selected <- unlist(
    lapply(rows_by_class, function(rows) {
      sample(rows, size = floor(length(rows) * proportion))
    }),
    use.names = FALSE
  )
  sort(selected)
}

    • 灵敏度或召回率为 TP/(TP+FN)TP/(TP+FN)；
    • 特异度为 TN/(TN+FP)TN/(TN+FP)；
    • 精确率为 TP/(TP+FP)TP/(TP+FP)；
    • 准确率为 (TP+TN)/N(TP+TN)/N。

    13.3 ROC 与精确率—召回率曲线

    ROC 曲线展示阈值变化时灵敏度与假阳性率的关系。ROC AUC 衡量排序区分度，不衡量校准。AUC 很高并不表示预测概率等于实际事件率。

    事件稀少时，精确率—召回率曲线尤其有信息。其精确率基线是事件发生率，不同于 ROC 图中的对角随机线。

    下面的实现只在每个相同预测分数区段的末尾计算阈值点，因此能够正确处理并列分数。

    binary_prediction_curves <- function(y, p) {
  stopifnot(
    length(y) == length(p),
    all(y %in% c(0, 1)),
    all(is.finite(p)),
    sum(y == 1) > 0,
    sum(y == 0) > 0
  )
  ordering <- order(p, decreasing = TRUE)
  p_sorted <- p[ordering]
  y_sorted <- y[ordering]
  tp_cumulative <- cumsum(y_sorted == 1)
  fp_cumulative <- cumsum(y_sorted == 0)
  tie_end <- !duplicated(p_sorted, fromLast = TRUE)
  tp_at_threshold <- tp_cumulative[tie_end]
  fp_at_threshold <- fp_cumulative[tie_end]
  thresholds <- p_sorted[tie_end]
  positives <- sum(y == 1)
  negatives <- sum(y == 0)

  roc <- data.frame(
    fpr = c(0, fp_at_threshold / negatives),
    tpr = c(0, tp_at_threshold / positives),
    threshold = c(Inf, thresholds)
  )
  pr <- data.frame(
    recall = c(0, tp_at_threshold / positives),
    precision = c(1, tp_at_threshold / (tp_at_threshold + fp_at_threshold)),
    threshold = c(Inf, thresholds)
  )
  list(roc = roc, pr = pr)
}

    16 练习与参考答案

    16.1 概念练习

    1. 优势与概率。 基线概率为 0.10，优势比为 2。新概率是多少？
      答案： 基线优势为 0.1/0.9=1/90.1/0.9=1/9；翻倍后为 2/92/9；新概率为 (2/9)/(1+2/9)=2/11≈0.1818(2/9)/(1+2/9)=2/11\approx0.1818。概率没有翻倍。

    2. 尺度转换。 Logistic 的 balance 系数以每个货币单位估计。如何得到 100 个单位的优势比？
      答案： 计算 exp(100β̂)\exp(100\hat\beta)，不是 100exp(β̂)100\exp(\hat\beta)，也不是概率变化。

    3. 预测类型。 Logistic 模型中，哪个 predict() 类型返回对数优势？
      答案： type="link"；type="response" 返回概率。

    4. 符号变化。 为什么 studentYes 在仅含 student 的模型和调整模型中可能符号相反？
      答案： 两者估计不同的边际关联和条件关联，而且不同 student 状态的 balance 分布不同。

    5. Probit 单位。 预测概率从 0.20 增加到 0.26。绝对变化是多少？
      答案： 0.06，即 6 个百分点。相对增加为 0.06/0.20=30%0.06/0.20=30\%。

    6. Poisson 解释。 log 链接 Poisson 模型中，exp(βj)\exp(\beta_j) 表示什么？
      答案： 其他模型项不变时，xjx_j 增加一个单位，期望计数乘以该值；存在暴露量 offset 时，对应期望率的乘法变化。

    7. Quasi-Poisson。 系数、标准误和普通 AIC 哪些会改变？
      答案： 同一均值模型的系数不变；标准误乘以 ϕ̂\sqrt{\hat\phi}；普通 AIC 不可用。

    8. Offset。 协变量不变而暴露量翻倍时，期望计数和期望率如何变化？
      答案： 期望计数翻倍；期望率不变。

    9. 诊断。 对于以线性项进入模型的预测变量，η̂\hat\eta 对该变量的图为直线，能否证明线性假设？
      答案： 不能，这是模型公式决定的。应检查残差模式和灵活替代模型。

    10. 预测。 ROC AUC 很高的模型是否仍可能校准很差？
      答案： 是。排序区分度和概率校准是不同性质。

    18 总结与出门测

    让学生不看输出，完成以下四句话：

    1. Logistic 回归中，coef() 位于 ______ 尺度，exp(coef()) 给出 ______。
    2. Probit 回归中，0.06 的概率差是 ______ 个百分点。
    3. Poisson 回归中，exp(coef()) 表示 ______ 的乘法变化。
    4. 率模型中，响应变量仍然是 ______，offset(log(exposure)) 的系数固定为 ______。

    参考答案：对数优势；优势比；6；期望均值或率，视具体项而定；计数；1。

    最后不要给学生留下“选择 p 值最小的模型”这种印象。应强调：先明确响应与暴露量，再识别解释尺度，使用基于模型的诊断，并以有实际意义的单位报告预测及不确定性。

    18.1 一分钟板书总结

    课程最后保留以下四组对应关系：

    • Logistic：β̂\hat\beta → 对数优势；exp(β̂)\exp(\hat\beta) → 优势比。
    • Probit：β̂\hat\beta → 正态指数变化；使用预测概率解释。
    • Poisson：β̂\hat\beta → 对数期望计数；exp(β̂)\exp(\hat\beta) → 均值比或率比。
