    为什么要学交叉验证

    一句话 / in one sentence

    交叉验证（cross-validation, CV）是用同一批数据，估计模型在”没见过的数据” 上会有多好的一种方法。

    Cross-validation estimates how well a model will perform on data it has not seen, using only the data you have.

    0.1 它解决的是什么问题

    回忆你们在变量选择那一节学到的三件事。stepwise 的三个毛病里， 第一个毛病就是 CV 要治的病：

    stepwise 的毛病 具体表现 CV 能治吗
    ① 准则都是样本内的 adjusted \(R^2\)、AIC、BIC 都用同一批数据既选模型又评模型 ✅ 这就是 CV 存在的理由
    ② 搜索是贪心的 一次只动一个变量，进去的出不来 ❌ 换准则救不了，要靠全子集或正则化
    ③ 结果不稳定 起点、方向、并列时的取舍都是任意约定 ⚠️ 部分能（CV 自己也不稳，见 §3.4）

    核心矛盾：

    你手头只有一批数据，但你真正想知道的是 “这个模型拿去用在明天的新病人/新客户身上，会错多少？”

    样本内误差（in-sample error）永远回答不了这个问题—— 因为它按定义就是拿同一批数据算的。 CV 就是那个”假装有新数据”的技巧。

    0.2 三个必须先分清的”误差”

    这是全文最重要的一组定义。必须把下面三个词严格分开，否则后面全乱：

    名称 符号 定义 能不能直接算出来
    训练误差
    Training error    		 \(\overline{\mathrm{err}}\) 在拟合用的这批数据上的平均损失 ✅ 直接算（就是 mean(resid(m)^2)）
    测试误差
    Test error    		 \(\mathrm{Err}_{\mathcal T}\) 在一批固定的新数据 \(\mathcal T\) 上的平均损失 ❌ 除非你真有一批新数据
    期望测试误差
    Expected test error    		 \(\mathrm{Err}\) 对所有可能的新数据取期望 ❌ 理论上存在，算不出来

    形式化地写： 设损失是平方误差，\(\hat f\) 是在训练集 \(\{(x_i,y_i)\}_{i=1}^n\) 上拟合的模型，

    \[ \underbrace{\overline{\mathrm{err}} = \frac1n\sum_{i=1}^n \bigl(y_i-\hat f(x_i)\bigr)^2}_{\text{训练误差：可以算，但有偏}} \qquad \underbrace{\mathrm{Err}_{\mathcal T} = \frac1{|\mathcal T|}\sum_{i\in\mathcal T}\bigl(y_i-\hat f(x_i)\bigr)^2}_{\text{测试误差：要一批新数据}} \]

    \[ \underbrace{\mathrm{Err} = \mathbb E\bigl[\,(Y-\hat f(X))^2\,\bigr]}_{\text{期望测试误差：真正的目标}} \]

    🔴 为什么训练误差不能用？

    因为 \(\hat f\) 是看着这批数据挑出来的。它当然在这批数据上表现好—— 这不是证据，这是循环论证。

    而且越灵活（越复杂）的模型，训练误差只会越小。 用训练误差选模型，你永远会选到最复杂的那一个。 （§2 会用一个模拟把这件事量化出来。）

    CV 的定位：

    CV 不是测试误差，也不是期望测试误差。 CV 是 \(\mathrm{Err}\) 的一个估计量（estimator）。 它有偏、有方差，需要讨论它估得准不准——这正是 §3 的内容。

    第一部分：定义与方法

    1. 交叉验证的定义

    1.1 一般定义

    设：

    • 数据 \(\mathcal D = \{(x_1,y_1),\dots,(x_n,y_n)\}\)；
    • 损失函数 \(L(y,\hat y)\)（回归常用 \(L=(y-\hat y)^2\)；分类常用 0-1 损失）；
    • \(\mathcal A\) 是一个完整的建模流程（fitting procedure）： 输入训练集，输出一个预测函数 \(\hat f\)。 注意 \(\mathcal A\) 可以包含”选变量”“调超参数”“做标准化”等所有步骤。

    把 \(\mathcal D\) 随机划分成 \(K\) 个大小相近的折（folds）\(\mathcal D_1,\dots,\mathcal D_K\)。 对每个 \(k=1,\dots,K\)：

    1. 用除第 \(k\) 折以外的数据训练：\(\hat f^{(-k)} = \mathcal A\bigl(\mathcal D \setminus \mathcal D_k\bigr)\)；
    2. 在留出的第 \(k\) 折上算损失： \[\mathrm{CV}_k = \frac{1}{|\mathcal D_k|}\sum_{i\in\mathcal D_k} L\bigl(y_i,\ \hat f^{(-k)}(x_i)\bigr)\]

    \(K\) 折交叉验证的估计量就是这 \(K\) 个值的平均：

    \[ \boxed{\ \widehat{\mathrm{CV}}_K = \frac1K\sum_{k=1}^{K}\mathrm{CV}_k = \frac1K\sum_{k=1}^{K}\frac{1}{|\mathcal D_k|}\sum_{i\in\mathcal D_k} L\bigl(y_i,\ \hat f^{(-k)}(x_i)\bigr)\ } \]

    三个必须注意的细节：

    1. 下标 \((-k)\) 是全部关键。 预测 \(x_i\) 用的模型没有见过 \(y_i\)。 这就是”假装有新数据”的全部含义。
    2. 每一折的预测都来自不同的模型。 你有 \(K\) 个不同的 \(\hat f^{(-k)}\)， 最后并不选其中一个，只是把它们在留出折上的表现平均起来。
    3. \(\mathcal A\) 是整个流程。 如果流程里包含”先选变量再拟合”， 那么选变量也必须在折内做。做错了就是数据泄漏（§3.6）。

    # 一个通用的 K 折 CV 函数 -------------------------------------------------
cv_error <- function(formula, data, K = 10, seed = 1) {
  set.seed(seed)
  n    <- nrow(data)
  fold <- sample(rep(1:K, length.out = n))     # 尽量均分到 K 折
  errs <- numeric(K)
  for (k in 1:K) {
    train <- data[fold != k, ]
    test  <- data[fold == k, ]
    fit   <- lm(formula, data = train)          # 只用训练折拟合
    pred  <- predict(fit, newdata = test)       # 在留出折上预测
    errs[k] <- mean((test$hipcenter - pred)^2)
  }
  mean(errs)
}

    1.3 CV 估计的到底是什么

    这一点很多人搞错，值得单独强调。

    CV 估计的不是”某一个模型的测试误差”，而是”你这套建模流程 \(\mathcal A\) 的测试误差”。

    区别在哪？

    • 如果你固定一个模型（比如 hipcenter ~ Ht），那 \(\mathcal A\) 就是”拟合这一个模型”， CV 估的就是它的测试误差；
    • 但如果 \(\mathcal A\) 是”先用 CV 选出最好的模型，再拟合它”， 那么 CV 估的是这个选模型流程的测试误差—— 这就是嵌套 CV（§4.2）要处理的事。

    💡 记住这句话： CV 衡量的是流程，不是模型。 你往流程里塞进越多”看着数据做决定”的步骤（选变量、挑超参数、挑阈值……）， 用普通 CV 报出来的数字就越乐观。

    1.4 损失函数的选择

    CV 的框架不依赖具体损失，换损失就是换”什么叫错”：

    任务 常用损失 R 里怎么写
    回归 平方误差 \((y-\hat y)^2\) → MSE mean((y - pred)^2)
    回归（抗异常值） 绝对误差 \(\lvert y-\hat y\rvert\) → MAE mean(abs(y - pred))
    分类 0-1 损失 → 错误率 mean(y != pred)
    分类（概率） 对数损失 / 偏差 -mean(y*log(p) + (1-y)*log(1-p))
    计数 Poisson 偏差 -2*mean(dpois(y, pred, log=TRUE))

    选哪个损失，取决于你关心什么。 如果异常值很贵，用 MAE； 如果大误差特别不可接受，用 MSE（它惩罚大误差更重）。

kfold_mse <- function(formula, data, K = 10, seed = 303) {
  set.seed(seed)
  n    <- nrow(data)
  fold <- sample(rep(1:K, length.out = n))
  mean(sapply(1:K, function(k) {
    tr <- data[fold != k, ]; te <- data[fold == k, ]
    mean((te$y - predict(lm(formula, data = tr), newdata = te))^2)
  }))
}

    3. 主要方法与关键问题

    3.1 留出法（Validation Set / Hold-out）

    最原始的做法： 把数据分成两部分，一部分训练、一部分评估。

    优点： 简单、快、独立于模型（任何模型都能用）。

    缺点（两个，都很致命）：

    1. 只用了一部分数据训练 —— 剩下的数据”浪费”了。样本量本来就小时，这很痛。
    2. 结果高度依赖”怎么分” —— 换一个随机种子，误差估计可能差很多。
    # 同一个模型，只换划分方式，看估计值抖动多大
holdout_mse <- function(data, prop = 0.7, seed) {
  set.seed(seed)
  n     <- nrow(data)

  m     <- lm(y ~ x1 + x2 + x3 + x4, data = train)
  mean((test$y - predict(m, newdata = test))^2)
}

    🔴 单次留出法的估计值可以抖到 ±0.9 以上。 用它来选模型，等于把结论交给随机数。 这就是为什么需要 K 折：用”平均 K 次”来压住这个方差。

    3.2 K 折交叉验证

    做法： 分成 \(K\) 折，轮流留一折出来当测试集，共拟合约 \(K\) 次。

    \(K\) 怎么选？ 这是本节的中心问题。\(K\) 同时影响偏差和方差：

    训练集大小 偏差 方差 计算量
    \(K\) 小（如 2、5） 小 偏大（低估真实表现） 大 小
    \(K = 10\) \(0.9n\) 略偏大 中 中
    \(K = n\)（LOOCV） \(n-1\) 几乎无偏 大 大（但有捷径）

    直观理解这个权衡：

    • 偏差从哪来： 用 \(n(1-1/K)\) 个点训练，比用 \(n\) 个点训练学得差一点， 所以 CV 误差会略微高估真实误差。\(K\) 越大，训练集越接近 \(n\)，偏差越小。
    • 方差从哪来： \(K\) 折之间高度相关（训练集几乎重叠）。 \(K\) 越大，\(K\) 个估计量之间的相关性越强，平均掉的东西越少， 而且每个留出折越小、目标量越”抖”。所以 \(K=n\) 时方差最大。

    \(K=n\)（LOOCV）什么时候用？ 样本量很小（\(n<50\)）时， 或者当你有 §3.3 那种闭式捷径、算起来几乎免费时。

    3.3 留一法（LOOCV）与帽子矩阵捷径

    LOOCV = \(K=n\) 的 K 折：每次只留 1 个观测，用其余 \(n-1\) 个拟合，预测那 1 个。

    \[ \mathrm{LOOCV} = \frac1n\sum_{i=1}^{n} L\bigl(y_i,\ \hat f^{(-i)}(x_i)\bigr) \]

    问题： 要拟合 \(n\) 次。\(n=10^5\) 时不可行。

    但对线性模型（最小二乘）有一个漂亮的闭式解：

    \[ \boxed{\ \mathrm{LOOCV} = \frac1n\sum_{i=1}^{n}\left(\frac{e_i}{1-h_{ii}}\right)^2\ } \]

    其中 \(e_i\) 是普通残差，\(h_{ii}\) 是帽子矩阵的对角元（杠杆值）。

    这个公式为什么成立（直觉）：

    • \(h_{ii}\) 大 ⇒ 第 \(i\) 个点在 \(x\) 空间很”特别” ⇒ 回归线被它拉过去了；
    • 于是 \(e_i\) 会偏小——模型”迁就”了这个点；
    • \(1/(1-h_{ii})\) 就是把这个迁就修回来的修正量。 \(h_{ii}\to1\) 时修正量爆炸，正说明这种点的留一残差极不可靠。

    跟你们学过的帽子矩阵讲义直接接上： 这就是杠杆值的用途之一。

    # 两条路都算一遍，验证恒等式
loocv_hat <- function(formula, data) {
  m <- lm(formula, data)
  mean((resid(m) / (1 - hatvalues(m)))^2)
}
loocv_refit <- function(formula, data) {          # 老老实实重拟合 n 次
  n <- nrow(data)
  mean(sapply(1:n, function(i) {
    m <- lm(formula, data = data[-i, ])
    (data[[all.vars(formula)[1]]][i] - predict(m, newdata = data[i, ]))^2
  }))
}

    两者差异在 1.33227e-15 量级—— 就是浮点误差。 恒等式成立。

    💡 教学要点： 这个捷径只对线性模型且损失是平方误差时成立。 逻辑回归、随机森林、任何带超参数调优的流程——都不能用， 老老实实重拟合。 而且很多包的”LOOCV”默认就用这个公式，你至少要能判断它对你的模型成不成立。

    3.4 重复 K 折（Repeated K-fold）

    CV 估计本身有随机性：换个随机种子，结果就变。 重复 K 折就是把整个 K 折过程独立重复 \(R\) 次（每次重新划分），再平均。

    • 好处：方差显著降低；还能顺便给出一个标准差，让你知道这个估计有多稳。
    • 代价：计算量 × \(R\)。
    • 注意：重复 \(R\) 次并不能降低”训练集比全体小”带来的偏差—— 它只压方差，不纠偏差。
    # 单个 10 折 vs 重复 10 折
one    <- kfold_mse(y ~ x1 + x2 + x3 + x4, dat, K = 10, seed = 1)
reps   <- sapply(1:50, function(r) kfold_mse(y ~ x1 + x2 + x3 + x4, dat, K = 10, seed = 1000 + r))
c(single_10fold = one,
  mean_of_50    = mean(reps),
  sd_of_50      = sd(reps),
  range_lo      = min(reps),
  range_hi      = max(reps))
#> single_10fold    mean_of_50      sd_of_50      range_lo      range_hi 
#>     3.7924137     3.8305600     0.0754582     3.6636607     4.0847469
    ggplot(data.frame(x = reps), aes(x)) +
  geom_histogram(bins = 18, fill = "steelblue3", colour = "white", linewidth = 0.3) +
  geom_vline(xintercept = one, linetype = 2, colour = "red3", linewidth = 0.8) +
  geom_vline(xintercept = mean(reps), colour = "grey20", linewidth = 0.8) +
  labs(x = "10 折 CV 估计值", y = "次数",

    🔴 这张图值得盯着看几秒。 第一次的结果（红虚线）落在分布的左侧， 与平均差了 0.038。

    如果两个候选模型的 CV 值只差 0.05，而 CV 自身的标准差是 0.075——那么”谁更好”这个结论基本是随机的。

    所以：报告 CV 结果时，一定要报告不确定性。 单次 CV 的一个数字，不足以支撑”模型 A 优于模型 B”的结论。 最省事的做法就是重复 K 折，报告均值 ± 标准差。

    另一个更好用的技巧：”一倍标准差规则”（one-standard-error rule）—— 在所有 CV 值落在”最优值 + 1 个标准差”范围内的模型里，选最简单的那个。 这是对”CV 最小值有噪声”的直接补救。

    3.5 数据泄漏（Data Leakage）

    这是新手最常犯、后果最严重的错误。

    规则：任何”看着数据做的决定”，都必须放进折内。 Anything that looks at the data must happen inside the fold.

    什么叫”看着数据做决定”？

    步骤 泄漏的做法 ❌ 正确的做法 ✅
    标准化 / 中心化 用全部数据算均值和标准差 折内算，用训练折的均值去中心化测试折
    缺失值填补 用全部数据算中位数填补 折内算中位数
    特征筛选 用全部数据算相关系数挑变量 折内挑变量
    主成分分析 用全部数据做 PCA 折内做 PCA，把载荷应用到测试折
    选超参数 用全部数据调参 折内调参（→ 嵌套 CV，§4.2）
    去掉离群值 用全部数据识别离群点 折内识别

    跑一个极端例子。 造 \(n=60\) 个观测、\(p=5000\) 个纯噪声变量， \(y\) 和它们完全独立。所以真实的测试误差就是 1（\(y\sim N(0,1)\)）。

    我们用”先在全样本上挑相关系数最高的 20 个变量，再拟合”这个流程：

    set.seed(7)
n2 <- 60; p2 <- 5000
X2 <- matrix(rnorm(n2 * p2), n2, p2)
colnames(X2) <- paste0("v", 1:p2)
y2 <- rnorm(n2)                     # y 与所有 X 完全独立
dd <- data.frame(y = y2, X2)

# 挑出与 y 相关系数绝对值最大的 20 个变量名
top20 <- function(yv, Xm) {
  cors <- sapply(seq_len(ncol(Xm)), function(j) cor(yv, Xm[, j]))
  colnames(Xm)[order(abs(cors), decreasing = TRUE)][1:20]
}
    # ❌ 泄漏：选变量时看到了全部数据
leaky <- function(K = 10, seed = 1) {
  set.seed(seed)
  sel  <- top20(dd$y, X2)                 # <-- 看了全部 60 个观测
  f    <- reformulate(sel, "y")
  fold <- sample(rep(1:K, length.out = n2))
  mean(sapply(1:K, function(k) {
    tr <- dd[fold != k, ]; te <- dd[fold == k, ]
    mean((te$y - predict(lm(f, data = tr), newdata = te))^2)
  }))
}

# ✅ 正确：选变量只在训练折内做
honest <- function(K = 10, seed = 1) {
  set.seed(seed)
  fold <- sample(rep(1:K, length.out = n2))
  mean(sapply(1:K, function(k) {
    idx <- fold != k
    sel <- top20(dd$y[idx], X2[idx, , drop = FALSE])   # <-- 只看训练行
    f   <- reformulate(sel, "y")
    mean((dd$y[!idx] - predict(lm(f, data = dd[idx, ]),
                               newdata = dd[!idx, ]))^2)
  }))
}

B <- 30
leak_v   <- sapply(1:B, function(b) leaky(seed = b))
honest_v <- sapply(1:B, function(b) honest(seed = b))

c(leaky_outside_fold = mean(leak_v),
  honest_inside_fold = mean(honest_v),
  truth_y_is_noise   = 1)
#> leaky_outside_fold honest_inside_fold   truth_y_is_noise 
#>           0.334156           1.605836           1.000000

    💡 结论非常刺眼：

    • 泄漏的做法报出 0.334 —— 看起来”还不错”， 甚至比真值 1 还小；
    • 正确的做法报出 1.606 —— 诚实地反映了 “这些变量根本没用，误差大约是 1 加上选变量的额外波动”；
    • 真实值是 1（\(y\) 是纯噪声）。

    泄漏把误差低估了 79%。 而在这个例子里，\(y\) 和任何变量都没有任何关系—— 泄漏的做法却让你以为找到了规律。

    这就是为什么数据科学竞赛里”排行榜分数”经常在私榜上崩掉。

    ⚠️ 一个诚实的补充： 并不是所有预处理泄漏都会造成明显偏差。 例如只做中心化/标准化、模型是普通最小二乘时， 线性变换不影响 \(\hat\beta\) 和预测， 这时”先标准化再 CV”和”折内标准化”结果完全一样。 我实测过，差异是 0.0000。

    但这不能成为习惯。 一旦换成需要调超参数的模型 （岭回归、lasso、KNN、SVM、神经网络）， 或者换成 PCA、特征筛选、填补缺失值——泄漏立刻会咬人， 就像上面这个例子一样。规则要一刀切地遵守，不要赌。

    第二部分：适用情况

    4. 什么情况下该用哪种 CV

    4.1 决策树：先问数据是什么结构

    不要上来就 K=10。先回答三个问题：

    对应的方案：

    数据结构 该用的 CV 为什么
    独立同分布（i.i.d.） K 折（K=5 或 10） 标准情形
    i.i.d. + 想要稳定估计 重复 K 折 压住划分带来的方差
    有分组 / 聚类 留一组法（Grouped / LOGO） 同一组的观测不能跨越折
    有层级（国家级→个人） 按最高层分组 预测目标是”新国家”
    有时间顺序 滚动 / 前推（rolling, forward-chaining） 绝不能用未来预测过去
    类别极不平衡 分层 K 折（Stratified） 保证每折的正例比例一致
    空间数据 空间分块（spatial block） 相邻点高度相关
    要用 CV 选模型并报告性能 嵌套 CV 见 §4.2

    4.2 嵌套 CV：当”选模型”本身也要被评估

    4.2.1 问题：用 CV 选模型，再用同一个 CV 报性能，会乐观

    这是最容易被忽略、也最影响结论的一个坑。

    错误流程（naive）：

    1. 在全部数据上做 10 折 CV；
    2. 挑 CV 误差最小的那个模型；
    3. 就报这个最小的 CV 误差当作”模型的性能”。

    错在哪？ 第 3 步报的数字是 12 个候选模型里的最小值。 最小值天然偏小——你从 12 个里挑了最好的那个， 等于用数据做了一次选择，却没有为这次选择付出代价。

    正确流程（nested）：

    • 外层（outer）CV：只用来评估，衡量”整套选模型流程”的性能；
    • 内层（inner）CV：只在外层训练集内部跑，用来选模型。
    外层第 k 折：
  ├─ 外层训练集 (9/10 的数据)
  │    └─ 内层 10 折 CV  →  选出最好的模型  ──┐
  └─ 外层测试集 (1/10 的数据)                  │
       └─ 用上面选出的模型 → 算误差  ←────────┘

    4.2.2 实测：乐观了多少

    sizes <- 1:12
forms <- lapply(sizes, function(s) reformulate(colnames(X)[1:s], response = "y"))

# 错误做法：在全部数据上选，然后报那个最小值
cv_naive <- sapply(forms, kfold_mse, data = dat, K = 10, seed = 303)
best_naive <- which.min(cv_naive)

c(selected_vars      = sizes[best_naive],
  reported_CV_error  = cv_naive[best_naive])
#>     selected_vars reported_CV_error 
#>           4.00000           3.72508
    # 正确做法：嵌套 CV
nested_cv <- function(data, forms, K_out = 10, K_in = 10, seed = 303) {
  set.seed(seed)
  n    <- nrow(data)
  out  <- sample(rep(1:K_out, length.out = n))
  sapply(1:K_out, function(k) {
    tr <- data[out != k, ]; te <- data[out == k, ]
    inner <- sapply(forms, kfold_mse, data = tr, K = K_in, seed = 500 + k)
    f_best <- forms[[which.min(inner)]]           # 选模型只在训练集里做
    mean((te$y - predict(lm(f_best, data = tr), newdata = te))^2)
  })
}

outer_errs <- nested_cv(dat, forms)
c(nested_CV_estimate = mean(outer_errs),
  outer_sd           = sd(outer_errs))
#> nested_CV_estimate           outer_sd 
#>            3.90610            2.34052

    把三个数字并排放：

  nested_CV_honest        = mean(outer_errs),
  optimism                = mean(outer_errs) - cv_naive[best_naive],
  optimism_pct            = 100 * (mean(outer_errs) - cv_naive[best_naive]) / cv_naive[best_naive])

    💡 读这三个数：

    • naive 报出 3.725；
    • nested 报出 3.906；
    • 乐观了 0.181 （约 5%）。

    在外层只有 10 折的情况下，这个差距看起来不大——但它是真实存在的系统性偏差， 而且会随着候选模型数量增加而放大。 如果你在 5000 个变量里做筛选，naive 的乐观程度可以到几十个百分点。

    🔴 什么时候必须用嵌套 CV？

    只要你的最终模型是”用数据选出来的”，就应该用。 包括： - stepwise / 全子集变量选择； - 调超参数（岭回归的 \(\lambda\)、lasso 的 \(\lambda\)、树的深度……）； - 从多个模型族里挑一个（线性 vs 树 vs 神经网络）； - 有”先做特征工程再建模”的完整 pipeline。

    什么时候不需要？ 如果你事先就固定了一个模型（比如”就用这 4 个变量”）， 没有任何”看着数据做的决定”，那普通 K 折 CV 就够了。

    4.3 分组 / 聚类数据：留一组法

    典型场景：

    • 每个病人测了 4 次 → 同一病人的观测高度相关；
    • 每个学校抽了 30 个学生 → 同校学生共享学校效应；
    • 每个受试者做了 3 个任务 → 同一受试者内部相关。

    这里的核心问题不是”哪种 CV 更准”，而是”你到底要预测谁”。

    4.3.1 一个会推翻直觉的例子

    set.seed(42)
G <- 60; per <- 4
grp <- factor(rep(1:G, each = per))
u   <- rnorm(G, sd = 3)[as.integer(grp)]          # 个体效应，方差 = 9
x   <- rnorm(G * per)
yv  <- 1 + 2 * x + u + rnorm(G * per, sd = 0.3)  # 残差方差 = 0.09
gd  <- data.frame(y = yv, x = x, grp = grp)

c(var_u = 9, var_e = 0.09, ICC = 9 / (9 + 0.09))
#>    var_u    var_e      ICC 
#> 9.000000 0.090000 0.990099

    注意 ICC（组内相关系数）≈ 0.99 —— 也就是说这个数据的 99% 变异来自”个体之间”，几乎不来自个体内部。

    我们用 \(y \sim x\) 这一个模型，跑两种 CV：

    # (a) 普通随机 10 折（无视分组）——重复 50 次取平均
set.seed(1)
random_cv <- mean(sapply(1:50, function(s) {
  set.seed(s); fd <- sample(rep(1:10, length.out = nrow(gd)))
  mean(sapply(1:10, function(k) {
    tr <- gd[fd != k, ]; te <- gd[fd == k, ]
    mean((te$y - predict(lm(y ~ x, data = tr), newdata = te))^2)
  }))
}))

# (b) 留一人法：整人一起留出
logo_cv <- mean(sapply(levels(gd$grp), function(g) {
  tr <- gd[gd$grp != g, ]; te <- gd[gd$grp == g, ]
  mean((te$y - predict(lm(y ~ x, data = tr), newdata = te))^2)
}))

c(random_10fold = random_cv, leave_one_person_out = logo_cv)
#>        random_10fold leave_one_person_out 
#>              12.0010              12.2401

    两种 CV 几乎一样：12 vs 12.24。 看起来”分组不分组的，没什么差别嘛”。

    现在算两个理论真值。 因为数据是我们自己造的，我们知道答案：

    m_pool <- lm(y ~ x, data = gd)
V <- vcov(m_pool)                      # 系数的不确定度

  truth_brand_new_person       = truth_new)

#>                      0.21781                      9.19531

    🔴 这张表是本节的全部要点，而且结论和你想的可能相反：

    数值 相对 CV 估计
    随机 10 折 CV 12 1.0×
    留一人法 CV 12.24 1.0×
    真值：见过的人的新观测 0.22 0.02×
    真值：一个全新的人 9.2 0.77×

    两种 CV 都没能给你正确答案，而且它们的差别小到可以忽略。

    • 对”预测已见过的人”这件事，CV（12） 高估了 55 倍；
    • 对”预测一个全新的人”这件事，CV（12） 又恰好接近真值（9.2）。

    为什么两种 CV 都不对？ 因为问题不在 CV 方案，在模型本身：

    \(y \sim x\) 这个模型根本没有”个体”这个概念。 它对所有人给出同样的截距。 而数据里 99% 的变异是人与人之间的差异—— 这个模型在结构上就无法表达这个差异。

    所以 CV 算出来的 12， 是”这个错误模型在留出数据上的误差”， 它既不是”见过的人”的误差（那个是 0.22）， 也不是”新人”的误差（9.2）——它俩差 42 倍。

    4.3.2 那什么时候”留一组”才是关键？

    上面的例子说明：CV 方案选错，不一定是最大的问题；模型选错更致命。 但”留一组”在下面这些情形里确实是决定性的：

    情形 随机 K 折会怎样 为什么必须留一组
    组内观测几乎重复（同一人多次测量、同一图像的多个补丁） 训练集里有这个人的其他测量，等于见过答案 测试折必须是不认识的人
    特征里含”组身份”信息（如”病人历史均值”这种 target encoding） 模型可以直接背出这个人的水平 留一组后这个特征对新组无意义
    目标是全新组（新医院、新学校、新设备） 随机 CV 回答的是另一个问题 只有留一组才对应部署场景
    组数少但组很大 训练/测试共享组，高估泛化能力 留一组才能暴露”跨组”的风险

    而 §3.5 那个特征筛选的例子，就是第二行的极端版本—— 只不过那里泄漏的不是”组身份”，而是”全样本的相关系数”。

    💡 所以正确的思考顺序是：

    1. 先问：我要预测的对象是什么？（新人？新组？未来的时间点？）
    2. 再问：我的模型能表达这个结构吗？（有没有个体效应项？要不要混合模型？）
    3. 最后才问：CV 该怎么分折，才能模拟第 1 步的场景？

    反过来做（先选 CV 再想问题）是最常见的错误。

    4.3.3 一个诊断工具：ICC

    组内相关系数（intraclass correlation, ICC） 告诉你”分组到底有多重要”：

    \[\mathrm{ICC} = \frac{\sigma_u^2}{\sigma_u^2+\sigma_e^2}\]

    • 本例 0.99 —— 极高，必须认真处理分组；
    • ICC 接近 0 ⇒ 组之间没差别，随机 K 折基本没问题；
    • 实践中 ICC > 0.1 就应该考虑分组结构了。

    怎么估 ICC？ 最简单的方法是拟合一个”随机截距模型”：

    # 用组均值近似：组间方差 / 总方差
gm  <- tapply(gd$y, gd$grp, mean)
icc_hat <- var(gm) / var(gd$y)
c(ICC_rough_estimate = round(icc_hat, 3), n_groups = length(gm))
#> ICC_rough_estimate           n_groups 
#>               0.81              60.00

    4.4 时间序列：不能用随机 K 折

    核心禁忌：绝对不能用未来数据预测过去。

    如果随机分折，训练集里会包含”未来”的观测， 于是模型偷看了未来，测试误差虚低得离谱。 在金融、需求预测、流行病学里，这会造成灾难性的错误结论。

    正确做法： 折必须按时间连续分块，并且训练集永远在测试集之前。

    随机 K 折（❌）        滚动 / 前推（✅）
时间 →                 时间 →
[■□■|□■|■■|□■]        [■■■|□        ]  第1折
 ■=训练 □=测试          [■■■■|□      ]  第2折
                        [■■■■■|□    ]  第3折
                        训练集只增不减，测试集永远在后面

    4.5 分层 K 折：不平衡数据

    问题： 如果正例只占 2%，纯随机分折可能某一折里一个正例都没有， 那一折的误差就无法定义（或者极不稳定）。

    做法： 在每个类别内部分别做随机划分，保证每折的类别比例与总体一致。

    4.6 CV 做不到什么

    必须知道 CV 的边界，否则会过度自信。

    CV 做不到 为什么 该用什么
    给出无偏的性能估计（流程含选择时） 选择本身消耗了信息 嵌套 CV
    告诉你模型对不对 它只衡量预测，不衡量因果、不检查函数形式 残差诊断、领域知识
    替代外部验证 CV 是同一批数据内部的重采样 真正的外部数据 / 时间外样本
    自动选出可解释的模型 预测最优 ≠ 解释最优 领域知识 + 简约性
    处理分布漂移（distribution shift） 它假设训练和未来的数据同分布 领域适应、重新加权
    在极小样本下可靠 一切估计都极不稳 见 §6.3
    用来做后续统计推断 选完模型再算 p 值，p 值有偏 样本分裂（sample splitting）/ 选择性推断

    🔴 最容易被忘掉的一条：CV 不能替代外部验证。 如果你的模型要部署到另一个医院、另一个国家、另一年的数据上， 只有真正的外部数据能验证它。 CV 再好，也只是”在这批数据内部看起来好”。

    cv_kfold <- function(formula, data, K = 10, seed = 7) {
  set.seed(seed)
  n    <- nrow(data)
  fold <- sample(rep(1:K, length.out = n))
  mean(sapply(1:K, function(k) {
    tr <- data[fold != k, ]; te <- data[fold == k, ]
    mean((te$hipcenter - predict(lm(formula, data = tr), newdata = te))^2)
  }))
}
cv_repeated <- function(formula, data, K = 10, R = 50) {
  v <- sapply(1:R, function(r) cv_kfold(formula, data, K = K, seed = 5000 + r))
  c(mean = mean(v), sd = sd(v))
}

    一倍标准差规则（one-standard-error rule）：

    在所有”CV 值 ≤ 最优值 + 1 个标准差”的模型里，选最简单的那个。

    理由： 既然 CV 区分不出这些模型，那就按简约原则选。 这既降低了过拟合风险，也让模型更好解释、更好维护。

    6. 常见陷阱与最佳实践

    6.1 十个最常见的错误

    # 错误 后果 正确做法
    1 预处理放在折外 性能虚高，可能完全无效 标准化、填补、PCA、筛选全部折内做
    2 用 CV 选模型又报同一个 CV 系统性乐观（§4.2） 嵌套 CV
    3 有分组却用随机 K 折 回答了错误的问题；若组内近乎重复则会严重低估（§4.3） 留一组法，并检查模型能否表达组结构
    4 时间序列用随机 K 折 偷看未来，结论无意义 滚动 / 前推
    5 只跑一次 CV 就下结论 结论可能是噪声 重复 K 折，报告 ± sd
    6 用训练误差选模型 永远选最复杂的 用 CV 或 AIC/BIC
    7 分类不平衡不分层 某些折没有正例 分层 K 折
    8 LOOCV 用在非线性模型上 帽子矩阵公式不成立 老实重拟合，或用 K 折
    9 报了 CV 却不说怎么分的 结果不可复现、无法评估 写明 \(K\)、种子、分组变量
    10 把 CV 当成外部验证 部署后性能崩塌 真正的外部数据集

    6.3 小样本怎么办

    \(n\) 很小时（比如 seatpos 的 38，或更小），CV 会遇到两个问题：

    1. 训练集太小 ⇒ 偏差大（模型学不好）；
    2. 折与折之间的差异大 ⇒ 方差大，结论不稳。

    可用的对策：

    对策 说明
    用 LOOCV 训练集最大（\(n-1\)），偏差最小。计算量对线性模型不是问题
    重复很多次 K 折 压方差，还能看分布
    报告不确定性 一定要报 sd 或区间，不能只报一个数
    一倍标准差规则 选不出就选最简单的
    不要过度比较模型 在 \(n=38\) 上比较 4 个模型，差距基本都在噪声里
    考虑 AIC/BIC 它们用全部数据拟合，在小样本下有时比 CV 更稳
    考虑 \(C_p\)、GCV 也是基于全部数据的准则，见变量选择那一节

    ⚠️ 一句诚实话： 在 \(n=38\) 的数据上，任何模型选择方法的结果都应该被当作”建议”而不是”结论”。 CV 能帮你排除明显糟糕的模型，但它没有办法在小样本上精确区分好模型和次好模型。 诚实报告”这几个模型我们区分不出来”，比硬选一个更专业。

    B. 与其它准则的关系

    准则 用全部数据拟合？ 用新数据评估？ 适用
    训练误差 ✅ ❌ 永远不要用来选模型
    Adjusted \(R^2\) ✅ ❌（只是惩罚项近似） 快速比较、同族模型
    AIC / BIC ✅ ❌（渐近近似） 大样本、嵌套模型比较
    \(C_p\) ✅ ❌ 线性模型
    CV ❌（要重拟合） ✅ 真的留出 通用，任何模型任何损失
    外部验证 — ✅✅ 最终的金标准

    CV 相对 AIC/BIC 的三个优势：

    1. 不依赖渐近理论——直接做留出，小样本也说得通；
    2. 能做任何模型——AIC 要算似然和有效参数个数，随机森林/GNN 很难；
    3. 能配合任何损失——MAE、AUC、分位数损失都可以。

    AIC/BIC 相对 CV 的优势：

    1. 只拟合一次，快得多；
    2. 对小样本的方差更小（因为用了全部数据拟合）；
    3. 有明确的理论性质（如 AIC 的渐近最优性）。

    实践建议： 两者都跑，看结论是否一致。 一致 → 更有信心；打架 → 说明数据里的信号不足以区分模型，要谨慎下结论。
