# SURF Posters

把每年的 SURF 海报复制到这个目录（PDF 或 PNG），会自动出现在对应年份的 SURF 项目页面上：

- `2026-knowledge-survival.pdf` / `.png` → SURF 2026
- `2025-breast-cancer.pdf` / `.png` → SURF 2025
- `2024-poisoning.pdf` / `.png` → SURF 2024
- `2023-dimred.pdf` / `.png` → SURF 2023
- `2022-psychometrics.pdf` / `.png` → SURF 2022

PDF 会显示为下载链接，PNG 会直接显示在页面上。放好后提交并 push，海报即上线。
